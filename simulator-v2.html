    About this simulation

    This is an interactive browser simulation of the K Scan AI Meta glasses experience. The 600×600 panel renders the real production HUD build (companion mode) — its state machine, message protocol, and result contract are unmodified. This outer page plays the role of the paired phone using synthetic, local, in-memory data only.

    No physical Meta hardware is connected. No camera or microphone access occurs anywhere on this page. No real account, backend, or commerce data is used — every result is a fictional fixture.

    Engineering-oriented scenario injection, protocol negative-tests, and a raw message log remain available in QA mode, and at the legacy image/text scan simulator and protocol test console.
